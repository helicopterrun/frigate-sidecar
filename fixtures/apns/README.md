# APNs golden fixtures

Six JSON files, one per payload shape the push engine can send:

- `alert-interrupt-tier.apns` -- a situation authored at Interrupt: a plain
  time-sensitive banner (`payload.build_payload`).
- `alert-present-tier.apns` -- the Phase-2 fallback: a Present-tier situation
  on a device with no push-to-start token falls back to the same alert shape.
- `live-activity-start.apns` -- the push-to-start push that creates a Live
  Activity (`activity.build_start`).
- `live-activity-update.apns` -- a silent ContentState update, no `alert` key
  (`activity.build_update`).
- `live-activity-escalation.apns` -- an `event: update` push that *also*
  buzzes: the activity advances and the banner/sound fire in the same push
  (`activity.build_escalation`).
- `live-activity-end.apns` -- resolution, with `dismissal-date` set so the
  activity fades on a tail (`activity.build_end`).

Each file is generated by `tests/test_golden_apns_fixtures.py` from a fixed,
canned input (deterministic `sent_at`/`timestamp`, fixed handles and ids) --
not hand-written. The test diffs the builder's current output against the
file on disk; a payload-builder change that alters what gets sent fails the
test with a diff and instructions to re-bless. Delete a fixture and rerun the
test to regenerate it from scratch, or re-bless all of them after an
intentional change:

```sh
APNS_GOLDEN_REGEN=1 pytest tests/test_golden_apns_fixtures.py
```

Every fixture carries a top-level `"Simulator Target Bundle"` key set to the
Elsinore app's real bundle id (`com.houseofpaimon.Elsinore`, from
`Elsinore.xcodeproj`), so a fixture can be replayed on a booted Simulator
without also passing a bundle id on the command line:

```sh
xcrun simctl push booted - < fixtures/apns/alert-interrupt-tier.apns
```

For a Live Activity push (`live-activity-*.apns`), the Simulator must already
be running a build with an active Live Activity for `SituationActivityAttributes`
(start/update/escalation) or a booted app to receive the alert fallback --
`simctl push` delivers the payload but does not itself create the activity.
